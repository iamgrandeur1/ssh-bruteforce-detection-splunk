# SSH Brute Force Detection & Authentication Analysis Using Splunk

This repository documents an SSH threat hunting and authentication analysis project using Splunk and Zeek SSH logs.

The project focused on identifying suspicious SSH activity, failed authentication attempts, and potential brute-force behavior within a monitored environment.

---

##  Technologies Used

- Splunk
- Zeek
- Kali Linux
- VirtualBox

---

##  Focus Areas

- Threat Hunting
- Authentication Analysis
- SSH Monitoring
- Brute Force Detection
- Detection Engineering
- SIEM Operations
